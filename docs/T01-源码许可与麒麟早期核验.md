## 2. 发行材料与许可处置

实际安装的 Harness 1.0.7 的 `RECORD` 包含 **51 个** `builtin/skills/{en,zh}/powerpoint/` 文件，包括提示词、指南、脚本、XSD 和许可文件。[英文技能独立许可](https://github.com/TencentCloud/octop-harness/blob/v1.0.7/src/octop_harness/builtin/skills/en/powerpoint/LICENSE.txt)对整套材料规定了额外限制；[中文技能](https://github.com/TencentCloud/octop-harness/blob/v1.0.7/src/octop_harness/builtin/skills/zh/powerpoint/SKILL.md)同样声明独立许可，[同步逻辑](https://github.com/TencentCloud/octop-harness/blob/v1.0.7/src/octop_harness/builtin/_sync.py)先复制英文树再覆盖中文。移除 `[all]` 或隐藏入口均不能排除这些字节。

本次新增 `scripts/strip_restricted_skills.py SITE_PACKAGES`，只处理显式指定的发行安装树：删除上述英文和中文完整目录，移除对应 RECORD 行，保留其他技能及组件版权、MIT/NOTICE 文件。RECORD 通过替换文件更新，避免改写 uv 硬链接所指向的共享缓存。安装树或包元数据缺失、重复时直接失败。

| 发行入口 | 本次处理位置与限制 |
| --- | --- |
| portable ZIP 与使用该 ZIP 的桌面包 | `desktop/portable/package.sh` 在安装完成后、压缩前物理裁剪，复用安装时选定的解释器，离线时不另行查找宿主 Python 3.12。当前桌面发布使用 Wails；旧 Electron 集成说明不能作为当前发行路径。 |

代码审查发现，镜像已有 `HOME=/data`，原缓存挂载却在 `/root/.cache/uv`；只裁剪安装树会把原始材料留在 `/data/.cache/uv`。使用官方 Python 3.12/uv 0.7、固定 Harness 1.0.7 和相同裁剪步骤构建最小本地镜像，再导出并逐层检查：对齐前缓存层残留 **51 个**受限文件，对齐后所有层残留 **0 个**，Harness 根 LICENSE 保留。该实测覆盖安装、缓存和裁剪边界，不是完整 Octop full/lite 或 FnOS 镜像构建通过。

裁剪不代表完整发行已完成许可审查。另已发现：专家库使用 Apache-2.0；PyMuPDF 1.28.2 的[官方 COPYING](https://github.com/pymupdf/PyMuPDF/blob/1.28.2/COPYING)为 AGPLv3，默认 full 镜像会选入 OCR extra；psycopg 3.3.4、pynput 1.8.2 各有 LGPL 许可。两份 Ark Pixel 字体内嵌信息对应 [2026.02.27 的 OFL 许可](https://github.com/TakWolf/ark-pixel-font/blob/2026.02.27/LICENSE-OFL)，FSPixelSansUnicode 字体虽有内嵌 Open Font License 声明，完整许可文本尚未核实。浏览器、OCR 权重和最终全部字体资源的分发材料仍需随选定候选核对，不能统称“整包 MIT”。
